# Comprehensive Fixes Applied

## Date: November 21, 2025

### 1. Mongoose Instance Fix (Critical)

**Problem**: All services were using separate `require('mongoose')` instances, causing disconnection issues and dbState=0 errors.

**Solution**: Updated all models to use shared mongoose instance from `shared/utils/database.js`

**Files Fixed**:
- ✅ `services/user-service/src/models/User.js`
- ✅ `services/campaign-service/src/models/Campaign.js`
- ✅ `services/campaign-service/src/models/CampaignTotals.js`
- ✅ `services/pledge-service/src/models/Pledge.js`
- ✅ `services/pledge-service/src/models/Outbox.js`
- ✅ `services/payment-service/src/models/Transaction.js`
- ✅ `services/notification-service/src/models/Notification.js`

**Change**:
```javascript
// Before
const mongoose = require('mongoose');

// After
const { mongoose } = require('../../shared/utils/database');
```

### 4. Validation Requirements by Service

#### User Service
**Required Fields**:
- `email` (valid email format)
- `password` (min 6 characters)
- `name`

**Optional Fields**:
- `phone`
- `role` (defaults to "user")

#### Campaign Service
**Required Fields**:
- `title` (max 200 chars)
- `description` (max 1000 chars)
- `goalAmount` (positive number)
- `category` (enum: medical, education, disaster, other)
- `startDate` (valid date)
- `endDate` (valid date, must be after startDate)
- `beneficiaryName`

**Optional Fields**:
- `story` (max 5000 chars)
- `currency` (defaults to "BDT")
- `beneficiaryRelation`
- `imageUrl`
- `documents` (array)
- `status` (defaults to "draft")

#### Pledge Service
**Required Fields (Authenticated Users)**:
- `campaignId`
- `amount` (positive number)

**Required Fields (Guest Users)**:
- `campaignId`
- `amount`
- `donorInfo.name`
- `donorInfo.email`

**Optional Fields**:
- `currency` (defaults to "BDT")
- `message`
- `isAnonymous` (defaults to false for authenticated, handled via donorInfo)

#### Payment Service
**Automatic Fields**:
- `idempotencyKey` (from header or auto-generated)
- `paymentIntentId` (generated by system)
- Status managed by state machine

### 8. Common Errors and Solutions

#### Error: "Missing required fields: goalAmount, startDate, beneficiaryName"
**Cause**: Incorrect field names in request body  
**Solution**: Use updated Postman collection with correct field names

#### Error: "Unexpected token : in JSON at position 9"
**Cause**: Shell escaping corruption in PowerShell/curl  
**Solution**: Use Postman ONLY for API testing

#### Error: dbState: 0 (disconnected)
**Cause**: Multiple mongoose instances  
**Solution**: All models now use shared mongoose instance (FIXED)

#### Error: Request timeout
**Cause**: bcrypt too slow or MongoDB connection issues  
**Solution**: Optimized bcrypt to 6 rounds, increased timeouts (FIXED)
